## 6. How to edit a product or add photos

**The easy way: the product editor.** Log in at `/admin`, choose **Products**, and add or edit products, upload
photos, set prices and place the candle flame, all on screen. The steps below are the by-hand way (editing the
file directly), which still works.

### 6a. Editing `Data/products.json`

All products live in `Data/products.json`. It's a text file in JSON format: be careful with commas and quotes,
because one typo stops the website from starting. A free online "JSON validator" can check the file
before you save it. After editing, **restart the website** (the file is read once when the site starts).

Each product looks like this (shortened):

```json
{
  "id": "red-grape",
  "sku": "CO-CAN-REDGRP",
  "slug": "red-grape",
  "name": "Red Grape",
  "category": "candles",
  "type": "candle",
  "shortDescription": "Juicy grape and rich sweetness: fruity, bold, luscious.",
  "description": "A two-tone rose and white candle in a rounded glass tumbler.",
  "scent": { "tags": [ "Juicy grape", "Fruity" ], "top": [], "heart": [], "base": [] },
  "wax": null, "vessel": "Rounded glass tumbler", "size": null, "weightGrams": null, "burnTimeHours": null,
  "priceEur": null,
  "compareAtPriceEur": null,
  "stockStatus": "enquire",
  "variants": [], "options": [],
  "images": [ { "file": "red-grape-1", "alt": "…", "source": "…", "flame": { "x": 0.5, "y": 0.33 } } ],
  "guides": [ "for-home", "for-her" ],
  "featured": false, "giftSet": false, "containsAlcohol": false,
  "paymentLink": null, "checkoutUrl": null,
  "instagramSource": "…",
  "todo": [ "Price", "Wax type" ]
}
```

What each field means:

| Field | Meaning |
|---|---|
| `id` | Internal name. **Never change it** after launch (carts and orders refer to it). |
| `sku` | Your stock code, shown on orders in the admin page. |
| `slug` | The web address: `/products/red-grape`. Changing it breaks old links. |
| `name` | Product name shown to customers. |
| `legacyNames` | Old names, so carts saved under an old name still work (e.g. `"Strawbery"`). |
| `category` | One of: `candles`, `shaped`, `wax`, `home`, `gifts`, `favours`. |
| `type` | `candle`, `wax-melts`, `wax-decor`, `diffuser`, `car-freshener`, `gift-set` or `favours`. Only `candle` gets the burning-wick flame. |
| `shortDescription` | One line shown on product cards when there are no scent tags. |
| `description` | The longer text on the product page. |
| `scent.tags` | Short scent words shown as tags (the first three also appear on cards). |
| `scent.top` / `heart` / `base` | Scent notes. Leave empty `[]` if unknown; when filled, the page shows a scent pyramid. |
| `contents` | For gift sets: what's in the box, one item per line. |
| `wax`, `vessel`, `size` | Text, or `null` if unknown. |
| `weightGrams`, `burnTimeHours` | Numbers, or `null` if unknown. |
| `priceEur` | Price in euros, e.g. `15.00`. **`null` = unknown**: the product shows "Price on request" and cannot be added to the cart. |
| `priceNote` | Text shown instead of a price when `priceEur` is `null`, e.g. `"€15–€20"`. |
| `compareAtPriceEur` | The old price, for offers. When set, the old price is shown crossed out and the card gets an "Offer" badge. |
| `stockStatus` | `in_stock`, `low_stock` ("Only a few left"), `out_of_stock` ("Sold out"), `made_to_order`, or `enquire` (not sold online, customers contact you). A product can only be bought online when it has a price **and** is `in_stock`, `low_stock` or `made_to_order`. |
| `variants` | Versions customers pick from (colours, scents). Each has its own `id`, `sku`, `name`, optional `swatch` colour, and can have its own `priceEur` and `stockStatus` (otherwise the product's are used). |
| `options` | Extra questions: `"type": "select"` with a list of `values` (e.g. wine colour), or `"type": "text"` for free text (e.g. scent wishes), with `required` true/false. |
| `images` | Photos, first one is the main photo. See 6b. |
| `guides` | Gift guide sections: `for-her`, `for-home`, `under-25`, `seasonal`. `under-25` is automatic: it lists every product that can be bought online at €25 or less, whatever its tags. Tagging a product `under-25` only affects "You may also like" suggestions. |
| `featured` | `true` = shown in the collection on the home page. |
| `giftSet` | `true` = gets a "Gift set" badge and appears in the gift-box reveal on the home page. |
| `containsAlcohol` | `true` = shows a wine notice and asks for age confirmation at checkout. |
| `paymentLink`, `checkoutUrl` | Only for a future payment provider that uses one payment link per product. Leave `null`. |
| `instagramSource` | Where the facts came from (for you; not shown to customers). |
| `todo` | Questions still open for this product (for you; not shown to customers). |

Common edits:
- **Set a price:** change `"priceEur": null` to e.g. `"priceEur": 14.00` and `"stockStatus": "enquire"` to `"stockStatus": "in_stock"`. For products with variants, set the price on the product (or on each variant if prices differ) and change each variant's `"stockStatus"` too.
- **Mark sold out:** `"stockStatus": "out_of_stock"`.
- **Run an offer:** set `priceEur` to the offer price and `compareAtPriceEur` to the normal price.
- **Stop selling something online but keep it visible:** `"stockStatus": "enquire"`.

### 6b. Adding or replacing photos

1. Put the new photo in the folder `ClientApp/assets-src/` (e.g. `ClientApp/assets-src/red-grape-new.jpg`).
2. Open `ClientApp/scripts/process-images.mjs` and add or change a line in the `productImages` list, for example:
   ```js
   { file: 'red-grape-2', src: OLD('red-grape-new.jpg') },
   ```
   `file` is the name the website uses for the photo. `OLD('…')` means "a file in `assets-src`"; `IG(18)` means
   Instagram screenshot 18. You can add `crop: [left, top, width, height]` (fractions from 0 to 1) to cut out
   part of the photo; otherwise the script crops to a 4:5 portrait, keeping the most interesting area.
3. Run the image script (needs Node.js installed):
   ```
   cd ClientApp
   npm run images
   ```
   This creates `red-grape-2-400.webp`, `-800.webp`, `-1200.webp` (for different screen sizes) and
   `red-grape-2-og.jpg` (for sharing on social media) in `wwwroot/images/products/`.
4. In `Data/products.json`, add the photo to the product's `images` list:
   ```json
   { "file": "red-grape-2", "alt": "Red Grape candle in a rounded glass on a wooden shelf", "source": "Owner photo, Dec 2026", "flame": { "x": 0.5, "y": 0.3 } }
   ```

   - `source` is just a note for you.
   - Put the best photo first: the first photo is used on cards and when the product is shared.
5. Restart the website.

### 6c. The flame position (`flame` x / y)

Candle cards "light up" when someone hovers over them (or, on phones, when the card scrolls into view).
The flame is drawn on top of the photo at the position of the wick:

- `x` = how far across the photo the wick is, from `0` (left edge) to `1` (right edge). `0.5` is the middle.
- `y` = how far down the photo the **top of the wick** is, from `0` (top edge) to `1` (bottom edge).

Example: `"flame": { "x": 0.55, "y": 0.13 }` puts the flame a little right of centre, near the top.
To find the numbers, open the 800-pixel version of the photo (`…-800.webp`, 800 × 1000 pixels) and divide
the wick's position in pixels by 800 (for x) and by 1000 (for y). Then check it on the site by hovering
over the card, and adjust in small steps (0.02).

If a candle's main photo has no `flame` (for example the Christmas Gold Tin Candle, whose wick isn't
visible), a little wick and flame appear at the top of the card's text area instead. Product cards use the
first photo's flame position. On the product page, every photo that has a `flame` position lights up on
hover; photos without one stay unlit. Products that are not `"type": "candle"` never get a flame.
